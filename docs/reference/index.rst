Reference
=========

Look up a setting, recipe or output name here. For an end-to-end analysis,
start with :doc:`../getting_started/quickstart` or
:doc:`../user_guide/results`.

- :doc:`configuration`: choose continuum, host and uncertainty options.
- :doc:`recipes`: find line-complex IDs and coverage requirements.
- :doc:`measurement_dictionary`: map a scientific quantity to its native
  metric, archived key, unit and uncertainty.
- :doc:`warnings`: interpret diagnostic codes and choose a next action.
- :doc:`run_bundles`: understand storage, compatibility and portable models.
- :doc:`fit_performance`: control evaluation caches and warm starts.
- :doc:`api/index`: inspect current Python signatures and return types.
