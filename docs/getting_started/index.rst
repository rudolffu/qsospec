Getting started
===============

The shortest path to a measurement is :doc:`installation`, :doc:`dustmaps`,
then the :doc:`quickstart`. It uses a public SDSS quasar and needs no host
stellar templates.

If you already have spectra, use :doc:`choose_workflow` to select an entry
point. Read :doc:`spectral_basics` before adapting units or wavelength frames.
